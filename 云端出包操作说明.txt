【壹ZHANG核 V1 · 云端出包（GitHub Actions）操作说明】

══════════════════════════════════════════════════════
  为什么改用云端编译？
══════════════════════════════════════════════════════
本地编译失败的原因已查明：WorkBuddy 运行期间会启动一批后台服务，
占满系统管道资源，flutter 一启动就抢不到资源而猝死（黑窗口消失）。
这不是代码问题，也不是脚本问题——脚本格式已三重校验通过。

GitHub Actions 是 GitHub 官方的云端编译服务：用 GitHub 自己的服务器
编译，**完全不受你本机影响**，是目前最可靠的办法。

══════════════════════════════════════════════════════

【准备好的东西】
文件：D:\yizhanghe\壹ZHANG核-上传GitHub.zip  （约 103 KB，57 个文件）
内容：源码 + Android 平台骨架 + 云端编译配置文件
已剔除本机专属文件（local.properties / .dart_tool / build），这些上传会
导致云端编译失败。

══════════════════════════════════════════════════════

【操作步骤】（约 10 分钟，全程不需要敲命令）

第 1 步　解压
   在 D:\yizhanghe\ 下右键 壹ZHANG核-上传GitHub.zip → 全部解压缩
   解压后会得到一个文件夹，里面是 android、lib、pubspec.yaml 等

第 2 步　打开你的 GitHub 仓库
   浏览器打开 github.com → 点右上角头像 → Your repositories
   → 点你刚建好的那个仓库

第 3 步　进入上传页面
   在仓库页面点击绿色按钮 Add file → 下拉选 Upload files

第 4 步　拖拽上传
   把上一步解压出来的那个文件夹，整个拖进网页的拖拽区域
   （要拖文件夹本身，不要拖文件夹里面的单个文件）
   等文件列表全部显示出来、进度条走完

第 5 步　提交
   页面下方默认是 "Commit changes"，直接点最下面的绿色按钮提交
   建议 Commit 信息写：initial upload yizhanghe

第 6 步　等云端编译
   提交后页面顶部会出现一条黄色的“Actions 运行中”提示
   等待 5~10 分钟，变成绿色对勾即成功
   （如果变红色叉号，点进去看报错，把报错截图发半夏）

第 7 步　下载 APK
   进入仓库的 Actions 标签页 → 点最新那次绿色运行
   页面底部 Artifacts 区域 → 下载 app-release-apk
   下载到的是 zip，解压后里面的 app-release.apk 就是安装包
   拷到手机点击安装（需允许"安装未知来源应用"）

══════════════════════════════════════════════════════

【注意事项】

· 仓库必须是空的
  如果建仓库时勾了 README / .gitignore / License，文件会冲突。
  建议：把仓库文件全部删空，只留一个空仓库，再按上面步骤上传。

· 仓库名建议用英文
  若含中文或特殊字符不影响编译，但后续下载链接可能不便。

· 分支名
  上传并提交后文件在 main 分支上，工作流会自动触发。
  如果你建仓库时默认分支是 master，也一样会自动触发（配置里两个都写了）。
